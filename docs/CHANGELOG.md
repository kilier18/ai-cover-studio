## v1.0 正式版 — 2026-11-02

第一个正式版本。核心变化：**从「靠耳朵试参数」变成「先诊断 → 自动给参数 → 按原唱音色校正」**。

### 新增能力

- **PitchIn-Q 诊断（第 3 步）**：对比原唱干声与转换结果，逐条报
  - 音准偏差（音分，中位数口径）
  - 八度跳变、重复字、漏字、音量突变
  - 齿音过亮、过度平滑、整体音色偏亮 / 偏暗
  - 每一条都带**时间区间**，报告 schema `pitchinq.report/1`
- **自动填参**：诊断完点「应用」，亮度 EQ / 靠前度自动填好并写明理由。
- **共振峰（formant）滑杆**：0.80–1.10，音高不变、只缩放声道长度。
  实测某模型比原唱亮 +3.20 半音，`0.88` 一处即回到 −0.25 半音。
- **音色对齐（timbre match）**：按原唱频谱包络闭环校正。
  四个模型实测全部收敛到 **±0.5 半音**（原本 −6.61 / −6.03 / +0.73 / +0.28）。
- **三段 EQ**：亮度 `eq_air` / 靠前度 `eq_presence` / 厚度 `eq_body`（±6 dB）。
- **混响四参数**：量、衰减、预延迟、高频衰减；第 1 步填的参数会自动带进第 3 步。
- **母带匹配（Matchering）**：勾选后成品响度/频响对齐原曲。18 秒素材 0.41 秒，整首 4:50 约 10 秒。
- **按模型记住共振峰初值**：调好的值写进 `work/_ui_prefs.json`，下次选到该模型自动带出，标签显示 `·记忆`。
- **🔥 预热**：顺序读一遍 `models/mdxc/*.ckpt`、`rvc_models/*/*.pth|*.index`、`rvc_runtime/assets/{hubert,rmvpe}/*.pt`（约 5.7 GB，热态 2.6 秒）。服务启动 4 秒后自动跑一次。
- **⏪ 接着上次**：扫出最近的原曲 / 干声 / 伴奏 / 转换结果，一键载入，崩了不用从第 1 步重来。

### 简化

- 分离模型从 4 个收敛到 **2 个场景**：
  - 「标准流行」= `model_bs_roformer_ep_317_sdr_12.9755.ckpt`（人声 SI-SDR 21.96，人声/伴奏最稳）
  - 「重混响 / 效果器多」= `mel_band_roformer_kim_ft2_bleedless_unwa.ckpt`（非人声成分压得最狠，尾巴 −99 dB）
  - 去和声（karaoke）与去混响（dereverb）转为内部二次处理，不进下拉。
- 「净化人声」下线（`bleed_suppressor`）：收益不明显，还会吃气声。
- 「去和声」与「去混响」合并成一个下拉 `clean`：`none` / `backing` / `dereverb` / `both`，默认推荐 `backing`。
- 输出默认 **MP3 320k**。

### 性能

| 环节 | 之前 | 现在 | 说明 |
|---|---|---|---|
| 音色对齐（60 s 素材） | 6.2 s | **1.4 s** | 谱域解析式搜索 tilt，只做 1 次 STFT + 1 次 iSTFT，结果逐位等价 |
| 整首 5:53 全链 | ≈60 s | **33 s** | 共振峰 + 音色对齐 + 混响 + EQ + 母带 + MP3 |
| 每步固定开销 | 10–13 s | 热态≈0 | `🔥 预热` 把模型文件读进系统缓存 |

### 修复

- **导出「失败」其实文件在**：试听地址把 `?t=时间戳` 拼进了文件路径，`/media` 找不到文件（404）。改为 `&t=` 参数，4 处调用点全部改正。
- **音色对齐偶发崩溃**：参考干声比成品短几十毫秒时，旧代码把成品尾巴一起截掉，`voc + inst` 报
  `ValueError: operands could not be broadcast together with shapes (…,2) (…,2)`。
  现在参考只用于统计、输出保持原长，混音前再统一对齐一次。
- **日志落盘**：每个任务的完整日志写到 `work/_jobs/<任务id>.log`，界面报错带最后两行真实原因。
- **Matchering 降级**：母带匹配失败自动改为直接转码，照样出片（`matched=false`）。
- **诊断口径**：`mean_cents` 曾被八度错帧拽到 +59 音分并建议 `pitch −1`（实测中位 +1.6 音分）→ 改为在 ±600 音分内取中位数；评分从「绝对缺陷数」改为「每分钟缺陷密度」，长歌不再一律 0 分。
